Memex

This is a What?

A memex is a concept introduced in Vannevar Bush's article "As We May Think" from 1945. In the article, Bush envisioned a machine which could be used to store and link resources to one another which someone might use to offload some burden from the brain. This idea influenced the development of the world wide web, and a common implementation of it is the wiki.
